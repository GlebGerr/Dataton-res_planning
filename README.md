# Анализ и планирование трудозатрат проектов

Данный репозиторий содержит аналитический проект по исследованию системы учёта трудозатрат и разработке модели планирования ресурсов проектов на основе исторических данных списания рабочего времени сотрудников.

Проект выполнен в рамках кейса (дататона) и демонстрирует, как данные системы учёта времени могут использоваться для анализа проектной деятельности и поддержки управленческих решений.

# Описание проекта

В большинстве компаний сотрудники фиксируют затраченное время в системах учёта трудозатрат. Однако такие данные часто используются только для отчётности и редко применяются для анализа и планирования ресурсов.

В рамках данного проекта была проведена обработка исторических данных списания времени сотрудников с целью:

- анализа структуры трудозатрат;
- выявления проблем качества данных;
- сегментации проектов по масштабу;
- построения модели прогнозирования трудозатрат.

Результатом работы стал аналитический инструмент, позволяющий использовать исторические данные для планирования новых проектов.

---

# Цели проекта

Основные задачи проекта:

- анализ исторических данных списания рабочего времени сотрудников;
- выявление проблем структуры и качества данных;
- исследование распределения трудозатрат по проектам;
- сегментация проектов на типовые архетипы;
- разработка модели прогнозирования трудозатрат;
- создание прототипа инструмента планирования проектов.

# Как воспроизвести анализ

Для воспроизведения результатов выполните следующие шаги.

### 1. Клонировать репозиторий

git clone https://github.com/GlebGerr/Dataton-res_planning.git

### 2. Перейти в папку проекта

cd Dataton-res_planning

### 3. Установить зависимости

pip install -r requirements.txt

### 4. Открыть Jupyter Notebook

Перейти в папку: `notebook/` и открыть файл: `project_analysis.ipynb`

### 5. Запустить ноутбук

В ноутбуке необходимо выполнить все ячейки (**Run All**).

Ноутбук автоматически загрузит данные из папки `data` и воспроизведёт полный аналитический pipeline.

---

# Основные этапы анализа

Ноутбук включает следующие этапы анализа:

1. загрузку и объединение Excel-файлов;
2. нормализацию структуры данных;
3. диагностику качества данных;
4. очистку данных;
5. агрегирование данных на уровне проектов;
6. сегментацию проектов на архетипы;
7. построение аналитических визуализаций;
8. разработку модели прогнозирования трудозатрат;
9. демонстрацию интерактивного планировщика проекта.

---

# Интерактивный планировщик проекта

В ноутбуке реализован прототип **интерактивного планировщика трудозатрат**.

Он позволяет:

- выбрать тип проекта (малый, средний или крупный);
- задать предполагаемую длительность проекта;
- получить прогноз трудозатрат;
- увидеть рекомендуемое распределение ролей.

Планировщик основан на анализе исторических проектов и сегментации проектов на архетипы.
