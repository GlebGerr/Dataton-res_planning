# Анализ и планирование трудозатрат проектов

Данный репозиторий содержит проект по анализу использования трудовых ресурсов в проектной деятельности компании на основе исторических данных списания рабочего времени сотрудников.

Проект был выполнен в рамках кейса и демонстрирует, как данные системы учёта трудозатрат могут использоваться не только для отчётности, но и для анализа, прогнозирования и планирования ресурсов проектов.

---

# Цели проекта

Основные задачи проекта:

- проанализировать исторические данные списания рабочего времени сотрудников;
- выявить проблемы структуры и качества данных;
- провести исследование распределения трудозатрат по проектам;
- сегментировать проекты на типовые архетипы;
- разработать модель прогнозирования трудозатрат;
- создать прототип инструмента планирования трудозатрат для новых проектов.

# Как воспроизвести анализ

Для воспроизведения результатов выполните следующие шаги.

### 1. Клонировать репозиторий

git clone https://github.com/GlebGerr/Dataton-res_planning.git

### 2. Установить зависимости

pip install -r requirements.txt

### 3. Открыть Jupyter Notebook

Перейти в папку:

notebook/

и открыть файл:

project_analysis.ipynb


### 4. Запустить ноутбук

В ноутбуке необходимо выполнить все ячейки (Run All).

Ноутбук автоматически загрузит данные из папки `data` и воспроизведёт полный аналитический pipeline.

---

# Основные этапы анализа

Ноутбук включает следующие этапы:

1. загрузку и объединение Excel-файлов;
2. нормализацию структуры данных;
3. диагностику качества данных;
4. очистку данных;
5. агрегирование данных на уровне проектов;
6. сегментацию проектов на архетипы;
7. аналитические визуализации;
8. построение модели прогнозирования трудозатрат;
9. демонстрацию интерактивного планировщика проекта.
